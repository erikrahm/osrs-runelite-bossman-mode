# Bossman Mode

A RuneLite plugin for a "bossman" account: a bronzeman-style ruleset where **items are only ever unlocked by boss drops**.
Forked from [Another Bronzeman Mode](https://github.com/CodePanter/another-bronzeman-mode) (BSD-2).

## What it does (v0.1)
- **Source-gated unlocks.** An item becomes *unlocked* only when it drops from an allowlisted source: the 75 boss NPCs,
  the chest/event loot the RuneLite Loot Tracker reports (Barrows, Lunar Chest, CoX/ToB/ToA, Fortis Colosseum, Unsired,
  Tempoross, Wintertodt, Doom of Mokhaiotl, Maggot King), plus completion rewards (Fire/Infernal cape, Tokkul) and anything
  received in the Gauntlet lobby. Slayer drops, clue caskets, shops, skilling and sea loot never unlock anything.
  Once unlocked, copies from any source are fine (bronzeman semantics). Coins are locked until Brutus drops some.
- **Free items.** Everything on the wiki Tool page at base tier (`bossman/tools.json`) and access equipment
  (`bossman/access.json`: slayer gear, keys/totems, grapple, rope) is always allowed.
- **Ledger.** Every unlock is written to `~/.runelite/profiles/<profile>/bossman-mode-ledger.json` with its source, the KC
  at that source, and a timestamp; per-source kill counts are tracked too (and synced from "Your X kill count is" messages).
- **Restrictions.** Locked items are dimmed with a lock marker in the inventory, bank and equipment; hidden in GE search
  results; and cannot be *sold* on the GE (the `Offer` option is removed) — only unlocked items may be sold.
- **Unlock banner** captioned with the source and KC ("Crazy archaeologist — KC 14"), optional screenshot / chat / notification.
- **Ladder panel.** The 69-rung boss ladder (`bossman/ladder.json`): current rung, gate, collection-log items gating it
  (with drop rates and ✓), KC vs expected KC, and the **debt board** — pets/jars that become "debt" once KC reaches their
  drop rate, and 1/5,000+ "meme" items. Browse other rungs with `<` / `>`; no-log rungs (Gemstone Crab, Mimic…) can be marked
  complete by hand.
- Chat commands: `!bmcount`, `!bmrung`, `!bmbackup`, `!bmreset` (opt-in).

Requires the **Loot Tracker** plugin to be enabled for chest/event sources (NPC kills work without it).

## Building
```
./gradlew build
```
Run `BossmanModePluginTest` from `src/test` to launch a client with the plugin loaded.

## Data
`src/main/resources/bossman/*.json` are generated by `plugin-data/build_data.py` in the series project from the OSRS wiki
scrapes; regenerate and copy them in when the ladder or rules change. Extra unlock sources (e.g. a boss released after this
version) can be added in the plugin config without rebuilding.
